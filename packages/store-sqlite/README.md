# @activegraph/store-sqlite

SQLite-backed EventStore (better-sqlite3).

Part of [Active Graph](https://github.com/programmarchy/activegraph-typescript) — an event-sourced reactive graph runtime for auditable, forkable agentic systems.

## Install

```bash
npm install @activegraph/store-sqlite better-sqlite3
```

> Requires the following peer dependency, which you install yourself so you control the version (and the native build): `better-sqlite3`.
