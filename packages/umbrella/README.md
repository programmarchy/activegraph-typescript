# @activegraph/sdk

Active Graph SDK: the default install bundle re-exporting core + runtime + in-memory/SQLite stores + packs + Diligence pack + CLI.

Part of [Active Graph](https://github.com/programmarchy/activegraph-typescript) — an event-sourced reactive graph runtime for auditable, forkable agentic systems.

## Install

```bash
npm install @activegraph/sdk
```
