# @activegraph/runtime

Runtime, scheduler, queue, pattern engine, defineBehavior / defineRelationBehavior, replay, fork-and-diff.

Part of [Active Graph](https://github.com/programmarchy/activegraph-typescript) — an event-sourced reactive graph runtime for auditable, forkable agentic systems.

## Install

```bash
npm install @activegraph/runtime
```
